# LEYBO — этап 2: три визуальных направления главной

Дата: 2026-09-06. Контент реальный: товары, цены и фото взяты с действующего каталога ЛЕЙБО (8 моделей), тексты — из текущего тона бренда. Это КОНЦЕПТЫ для выбора направления, не финальный дизайн.

## Как смотреть

- Быстро: PNG в этой папке (`*-desktop.png`, `*-mobile.png`).
- Интерактивно (hover и адаптив вживую): открыть `design/mockups/direction-a.html`, `direction-b.html`, `direction-c.html` в браузере; мобильный вид — DevTools → 390px.

## Три направления — одна фраза на каждое

| Файл | Название | Суть одной фразой |
|---|---|---|
| `direction-a.html` | **A «Эволюция»** | Тот же магазин, но чисто: текущая структура, единые цвета/шрифты/отступы, аккуратная карточка с бейджами и состояниями — минимум риска, максимум порядка. |
| `direction-b.html` | **B «Премиум»** | Больше воздуха и тишины: одна крупная модель в кадре, тонкие линии, редакционная типографика — ощущение бутик-магазина, а не маркетплейса. |
| `direction-c.html` | **C «Конверсия»** | Каждый экран ведёт к покупке: оффер с ценой/выгодой/CTA, бейджи скидок и остатков, доверие строкой сверху и блоком гарантий. |

## Что общего у всех трёх (это бренд, сохраняется)

- Логотип ЛЕЙБО по центру шапки (в финале — реальный SVG), иконки поиск/избранное/корзина/кабинет.
- Фирменный оранжевый #FFA000 как ЕДИНСТВЕННЫЙ акцент.
- Мобильная нижняя навигация (Меню/Поиск/Избранное/Корзина/Кабинет).
- Шрифты Montserrat + Nunito Sans. Лицензии: SIL OFL (Google Fonts) — бесплатны для коммерческого использования, встраивание разрешено. Ограничений нет.
- Футер: юридические ссылки + соцсети.

## Состояния, уже показанные в макетах

- Скидка (−15% + старая цена), «Последний размер», «Нет вашего размера» (out-of-stock), skeleton-загрузка карточки (в A), hover-кнопка на карточке (в C наведение), индикаторы наличия (в C), бейдж корзины со счётчиком.
- Остальные состояния (empty/error формы, фокусы клавиатуры, лоадеры фильтров) войдут в полный комплект макетов после выбора направления.

## Контраст WCAG AA (проверено)

- #232323 / #111 текст на белом/светлом — 15:1+ ✅
- #767676 / #6E6E6E вторичный текст на светлом — 4.5–5.2:1 ✅ AA
- Чёрный текст на оранжевом #FFA000 — ~10.5:1 ✅ (оранжевый — фон для CTA, не цвет текста)
- Белый текст на оранжевом — ~2:1 ❌ — НЕ используется
- Внимание на реализацию: белый на красном бейдже #D64545 — 4.0:1; при сборке заменить на #C0392B (~4.6:1) или увеличить шрифт бейджа.
