## Открытые задачи по Багу B (дубли вариаций) — статус после ответа Кирилла

Кирилл: «POIZON api там подключена там и смотри».

Диагностика (завершена частично, Docker перезапускался):
- Дублей: 1 012 групп / 155 родителей (publish-вариации с идентичными атрибутами).
- У 50 из 155 родителей есть `_leybo_article` (маппинг на POIZON/dewu API).
- Синк-метаданные (`_leybo_synced/_cny`) у клонов 52 проверенных POIZON-товаров **отсутствуют у обоих клонов**; пример 20806 (Vans, синк работал) — дублей не имеет.
- Товар-пример 21567 (`Forum Low White Green`) — **без статьи POIZON** (ручной товар), клоны 21569/21570 без метрик синка. Это указывает: дубли 21567 — **не от синка**, а от импорта каталога; POIZON-связь пока не доказана для этой пары.

Следующий диагностический шаг (не выполнен): сопоставить `dup-variations-dryrun-20260908.csv` (цены клонов) с формулой синка (CNY × rate × K) и с `_leybo_k` родителей; проверить даты создания клонов против дат последних импортов WP All Import. Затем — вывод: «мусор импорта» (безопасно скрыть) vs «два SKU POIZON» (решение источника).
