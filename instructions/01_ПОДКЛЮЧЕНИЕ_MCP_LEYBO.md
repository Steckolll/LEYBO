# Подключение временного MCP к `leybo.store`

Этот файл — инструкция для ИИ-агента разработчика. Подключи отдельный MCP-доступ к WordPress-магазину ЛЕЙБО, проверь соединение и только после этого переходи к файлу `02_ТЗ_НА_ДОРАБОТКУ_LEYBO_STORE.md`.

## Параметры доступа

| Параметр | Значение |
|---|---|
| Имя MCP | `leybo-store-30d` |
| WordPress MCP endpoint | `https://leybo.store/wp-json/mcp/novamira` |
| Логин | `leybo_mcp_dev_20260826` |
| Пароль приложения | `<ПОЛУЧИТЬ У КИРИЛЛА ОТДЕЛЬНО>` |
| Уровень доступа | временный WordPress administrator через Novamira MCP |
| Начало срока | 26.08.2026, 10:00:10 МСК |
| Автоматическое окончание | 25.09.2026, 10:00:10 МСК |

Секрет намеренно не записан в Markdown. Если пароль приложения ещё не передан, остановись только на шаге подключения и запроси у Кирилла одно значение: `WP_API_PASSWORD`. Не проси основной пароль WordPress и не копируй чужую администраторскую учётку.

После дедлайна сервер отклоняет REST/MCP-аутентификацию с HTTP `401`, отзывает application password и снимает роль с временного пользователя. Продлить срок самостоятельно нельзя.

## Вариант 1 — Claude Code

Требуется Node.js 22 или новее. Проверь:

```powershell
node --version
npx --version
```

Добавь MCP в user scope. Подставь отдельно полученный пароль вместо плейсхолдера; не сохраняй эту команду в репозитории:

```powershell
claude mcp add --scope user --transport stdio leybo-store-30d `
  -e WP_API_URL=https://leybo.store/wp-json/mcp/novamira `
  -e WP_API_USERNAME=leybo_mcp_dev_20260826 `
  -e WP_API_PASSWORD="<ПАРОЛЬ_ОТ_КИРИЛЛА>" `
  -e OAUTH_ENABLED=false `
  -- npx -y @automattic/mcp-wordpress-remote@0.4.0
```

Если сервер с таким именем уже существует, сначала посмотри его через `claude mcp get leybo-store-30d`. Удаляй и пересоздавай только эту запись, не трогай остальные MCP.

Перезапусти сессию Claude Code и открой `/mcp`. Сервер `leybo-store-30d` должен иметь статус `connected`.

## Вариант 2 — другой MCP-клиент

Если клиент умеет запускать stdio MCP, добавь эквивалентную конфигурацию в его локальное хранилище. Файл с секретом обязательно исключи из Git:

```json
{
  "mcpServers": {
    "leybo-store-30d": {
      "type": "stdio",
      "command": "npx",
      "args": ["-y", "@automattic/mcp-wordpress-remote@0.4.0"],
      "env": {
        "WP_API_URL": "https://leybo.store/wp-json/mcp/novamira",
        "WP_API_USERNAME": "leybo_mcp_dev_20260826",
        "WP_API_PASSWORD": "<ПАРОЛЬ_ОТ_КИРИЛЛА>",
        "OAUTH_ENABLED": "false"
      }
    }
  }
}
```

Не переключай эту учётку на OAuth: временный срок привязан именно к выделенному WordPress-пользователю и его application password.

## Обязательная проверка

После подключения выполни следующие действия через MCP:

- [ ] Вызови `mcp-adapter-discover-abilities`.
- [ ] Убедись, что сервер представился как `Novamira` и доступны как минимум `novamira/execute-php`, `novamira/read-file`, `novamira/write-file`, `novamira/edit-file`, `novamira/list-directory`, `novamira/run-wp-cli`.
- [ ] Сделай только чтение: через `novamira/execute-php` верни `home_url()`, логин текущего пользователя и его роли.
- [ ] Ожидаемый домен — `https://leybo.store`, пользователь — `leybo_mcp_dev_20260826`, роль — `administrator`.
- [ ] Не меняй сайт во время этой проверки.

Если соединение не поднялось, проверь по порядку: Node.js 22+, точный endpoint, `OAUTH_ENABLED=false`, отсутствие пробела/переноса в конце пароля, затем перезапуск MCP-клиента. Не устанавливай на WordPress другой MCP-плагин: Novamira уже работает.

## Границы доступа

MCP подключён к боевому `leybo.store`. Он даёт полный контроль, поэтому соблюдай правила:

- До отдельного согласования используй прод только для чтения, инвентаризации и получения согласованного backup. Разработку веди на тестовом стенде по второму файлу.
- Не создавай пользователей, application passwords, API-ключи, скрытые точки входа и другие способы сохранить доступ.
- Не меняй Novamira, настройки аутентификации и файл `wp-content/novamira-sandbox/leybo-temp-mcp-access.php` — это механизм автоматического отключения доступа.
- Не выгружай клиентские персональные данные. В локальной копии заказы и пользователей обезличь; исходящие письма, платежи, вебхуки и индексацию поисковиками отключи.
- Не редактируй WordPress core, WooCommerce core и файлы сторонних плагинов. Итоговый код должен жить в теме `isart-theme` и/или в отдельном проектном плагине.
- Не коммить MCP-конфиг и пароль. Не вставляй пароль в отчёты, Markdown, задачи, скриншоты или логи.

После завершения работ удали `leybo-store-30d` из своего MCP-клиента и локальные копии секрета. Доступ всё равно автоматически перестанет работать 25.09.2026 в 10:00:10 МСК.
